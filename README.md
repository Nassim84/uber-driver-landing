# Ned Driver Services

Site vitrine présentant les services de transport (chauffeur Uber).

## À propos

Ce projet affiche les services proposés : trajets, disponibilités, contact, etc.

## Stack

- [Next.js](https://nextjs.org/)
- React

## Démarrage

```bash
npm install
npm run dev
```

Le site est ensuite accessible sur [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Structure

```
├── app/ ou pages/     # Pages du site
├── public/            # Images, assets statiques
├── components/        # Composants réutilisables
└── styles/            # Feuilles de style
```
